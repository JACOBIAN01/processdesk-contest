# ProcessDesk

ProcessDesk is an htop-inspired desktop process monitor built using **Electron + React + Vite**. The repository deliberately uses an application-style layered architecture rather than putting all logic in a single file.

## Setup
```bash
npm install
npm run dev
```

## Checks
```bash
npm test
npm run lint:structure
```

Read `docs/REQUIREMENTS.md`, `docs/ARCHITECTURE.md`, and `docs/IPC_FLOW.md` before changing code. See `QUESTION_PAPER.md` for the contest brief.
